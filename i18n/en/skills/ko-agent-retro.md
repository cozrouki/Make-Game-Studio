## Project-specific changes

- Existing checks to read before proposing new ones: `.agent/tools/lint/unity_lint.py`
  (UL rules), Unity analyzers (`Default.ruleset`), `validate-commit.sh` /
  `validate-push.sh`, the game's EditMode/PlayMode tests, CI.
- Mechanical violations become a new UL rule or hook; `.claude/rules/*.md` keeps only
  judgement calls. Rule mirrors are regenerated by `scripts/gen-rule-mirrors.py`.
- Measures `AGENTS.md` / `CLAUDE.md` size and session-start hook output size.
- Information access includes Unity console, Editor.log, Player.log, profiler, build logs.
- Proposes only; in studio mode, steering/protocol changes go to the director as a ticket.
