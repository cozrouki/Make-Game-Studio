# /ko-grill — 집중 인터뷰

> 정본: `.claude/skills/ko-grill/SKILL.md` — 읽고 그대로 따른다.
> 인수: `[다듬을 계획 · 설계 · 결정 주제]`

**1. 결정 트리** — 주제를 결정과 하위 결정의 트리로 본다.

**2. 라운드** — 지금 물을 수 있는 질문(프런티어)을 한 번에, 번호와 추천 답을 붙여 묻고 답을 기다린다. 코드 · 문서로 알 수 있는 사실은 직접 찾고, 결정만 묻는다.

**3. 완료** — 프런티어가 비면 정해진 결정을 요약하고, 사용자가 확인하기 전에는 행동하지 않는다.
