# /ko-agent-retro — 에이전트 작업 환경 회고

> 정본: `.claude/skills/ko-agent-retro/SKILL.md` (문서 작성 기준 `WRITING.md`) — 읽고 그대로 따른다. 스프린트 회고는 `/retrospective`.
> 인수: `[세션 설명 — 생략하면 현재 세션]`

**1. 자료** — 대상 세션의 기록(대화 · 도구 로그)에서 오류 · 재시도 · 되돌림 구간을 찾는다.

**2. 후보** — 탐색 · 자동 검사(`unity_lint.py` · 분석기 · 커밋 훅 먼저 확인) · 코딩 표준 · 상시 지침 파일 크기 · 도구 비용 · 무효 지시 · 정보 접근 분류로 찾는다.

**3. 보고** — 심각도 순으로 근거 · 제안 · 분류를 보인다. 고치지는 않는다.
