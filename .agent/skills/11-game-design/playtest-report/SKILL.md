# Playtest Report — 플레이테스트 보고서

## 호출 시 동작

### `new` 모드 (`/playtest-report new`)
빈 보고서 템플릿 생성:
- 저장 경로: `doc/{GameName}/playtest/playtest-{YYYY-MM-DD}.md`
- `production/session-state/active.md`에서 현재 게임 파악

### `analyze <경로>` 모드
기존 플레이테스트 메모 파일을 읽고 구조화된 분석 보고서로 변환.

## `analyze` 모드 동작

기존 노트 파일을 읽어:
1. 관찰 내용을 Pain Points / Delight Moments / Bugs / Insights로 분류
2. 심각도별 정렬 (심각 → 경미)
3. 반복되는 패턴 식별 ("3명 이상의 테스터가 같은 지점에서 혼란")
4. 액션 아이템 우선순위화
5. 구조화된 보고서 형식으로 변환 후 저장 제안
